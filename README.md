What is a Transaction?
A transaction is a group of SQL statements that run together.
If one statement fails, all changes are undone.

ACID Properties
Atomicity: All or nothing
Consistency: Data stays correct
Isolation: Transactions do not affect each other
Durability: Committed data is saved forever

Why Transactions Matter
Prevent data loss
Handle errors safely
Manage multiple users at the same time
Used in banking systems for money transfers
